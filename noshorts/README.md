# NoShorts 0.5 — Chrome на Android

Приложение для стабильного Google Chrome (`com.android.chrome`). Ленты открываются по обычному адресу, а их содержимое закрывается непрозрачной маской с персональным посланием. Поиск, навигация, меню и сообщения остаются доступны. Shorts и дополнительные запреты пользователя по-прежнему блокируются.

| Сайт | Содержимое скрыто | Доступно без маски ленты |
|---|---|---|
| YouTube | Главная, подписки, trending/explore | Поиск, обычные видео, каналы, история, библиотека |
| Instagram | Главная, feed, explore, reel/reels | Direct, вход, профили, отдельные `/p` посты |
| LinkedIn | Главная и точный `/feed` | Сообщения, вакансии, поиск, профили, отдельные `/feed/update` посты |

## Послания

Для каждого сайта есть три фразы; они чередуются при новом входе. Имена — руководители материнских компаний: Сундар Пичаи (Google), Марк Цукерберг (Meta), Сатья Наделла (Microsoft). Например: «Сосать, Сатья Наделла. Мой ёбаный мозг ты сегодня не абузишь».

## Как работает

Служба получает текущий адрес из нативной строки Chrome либо URL документа WebView. Адрес произвольной ссылки не используется как доказательство перехода. Проверяются границы домена и сегментов пути. Главная — точный путь `/`, включая параметры; она не означает весь домен.

Лента маскируется внутри веб-страницы без Back и без перенаправления. Служба выбирает область `feed`/`main` из Accessibility-дерева Chromium, либо область WebView, и оставляет видимыми навигацию, поиск, поля ввода и открытые меню/диалоги. Страница с видимым полем пароля не маскируется. Новые посты и прокрутка обрабатываются повторным сканированием. Маски не перехватывают касания; поиск и кнопки работают через них.

Превью Shorts распознаются по `AccessibilityNodeInfo.targetUrl` Chromium и явной подписи действия `play Short`. Слово Shorts в обычном заголовке не скрывает карточку. Нажатия и переходы в YouTube `/shorts` закрываются отдельным покрытием с запросом Back. Дополнительные правила пользователя: одна строка `домен/путь`; один домен блокирует весь сайт.

Сканирование и окна масок выполняются в отдельном потоке, чтобы ожидание ответа Chrome не задерживало основной поток службы. Если после прокрутки строка Chrome скрыта, а пользователь нажал ссылку вне ленты или кнопку сообщений/профиля, служба может выполнить короткий жест вниз для возврата строки. Маска снимается после подтверждения нового адреса браузером; Back для этого не используется.

Приложение не использует VPN, интернет-разрешение, HTTPS-сертификаты, аналитику или историю посещений. Диагностика содержит подключение, число блокировок и масок, счётчики возврата строки Chrome. URL и тексты страниц в production не записываются.

## Установка и обновление

Установить APK поверх существующего и проверить службу «NoShorts — Chrome» в специальных возможностях Android. При запрете Android: Настройки → Приложения → NoShorts → ⋮ → Разрешить ограниченные настройки. На Samsung проверить ограничения батареи и спящие приложения.

Пакет `dev.noshorts.chrome` и ключ ClosePaw сохранены. SHA-256 сертификата: `25606cf1c6edbfdf2ce38285a9d1e94b5b5580b198c5e40f9ec4087f7cc447f2`. Ключи и пароли находятся только в секретах GitHub Actions. `versionCode = 100000 + github.run_number * 2`; не сбрасывать счётчик. Локальный код 2 предназначен для разработки.

CI устанавливает реально выпущенный 0.4.0 APK с проверенным SHA-256, обновляет его через `adb install -r`, проверяет сохранение времени установки, правил и разрешения службы, затем перезагрузку. Отдельное тестовое приложение управляет браузером без внедрения в процесс службы и повторной выдачи разрешений. Play Store отключён только на одноразовом эмуляторе, чтобы исключить изменение GMS/Chrome во время тестов.

## Проверка

Результаты: [TEST_RESULTS.md](TEST_RESULTS.md). Workflow `.github/workflows/build-noshorts.yml`, ветка `noshorts/android-verification` в `onemorewe/workbook-7`. ClosePaw и его workflow не изменены.

Android SDK 35, AGP 8.7.3, Gradle 8.9, Java 17. CI устанавливает Gradle. Для подписи нужны `KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, `NOSHORTS_VERSION_CODE`.

```bash
bash test-core.sh
gradle :core:verifyRules :app:lintRelease :app:assembleRelease :browser-tests:assembleDebug :browser-tests:assembleDebugAndroidTest
```

Живой YouTube проверяется отдельно. Детерминированные ленты на реальных адресах трёх сайтов подставляются через Chrome DevTools только в CI и проверяют маску, текст, поиск, меню, прокрутку, новые посты, безопасные переходы и вход. Production APK не содержит тестовых адресов или механизмов подстановки. Подстановка HTML не доказывает совместимость с авторизованной текущей лентой Instagram/LinkedIn.

## Ограничения

Маски работают после получения Accessibility-дерева; они не удаляют DOM и не останавливают загрузку изображений. При загрузке и быстрой прокрутке содержимое может мелькнуть. Изменения разметки сайта могут скрыть нужную кнопку или оставить фрагмент ленты видимым. Элементы Shorts без поддерживаемого адреса/действия могут остаться видимыми.

Работает в стабильном Chrome. Нативные приложения YouTube, Instagram и LinkedIn не обрабатываются. Samsung S24 Ultra/Android 16, управление батареей Samsung, split screen, инкогнито, полноэкранное видео и Custom Tabs непосредственно не проверены для 0.5. Пользователь подтвердил работу 0.3 на своём телефоне. При отключении службы, удалении или принудительной остановке приложения защита пропадает; приложение не является Device Owner.
