# NoShorts 0.3 — Chrome на Android

Собственное приложение, которое блокирует `youtube.com/shorts` по адресу текущей страницы Chrome. Обычные `watch`, поиск и главная YouTube остаются доступными. VPN, сертификат HTTPS и интернет-разрешение приложению не нужны.

## Установка

1. Установить подписанный APK и открыть NoShorts.
2. Разрешить службу «NoShorts — Chrome» в специальных возможностях Android.
3. Если Android запрещает включение: Настройки → Приложения → NoShorts → меню ⋮ → Разрешить ограниченные настройки, затем включить службу.
4. На Samsung проверить ограничения батареи и список спящих приложений для NoShorts.

После этого правило Shorts включено постоянно, без расписаний и временного разрешения. Сам факт установки без разрешённой службы не включает блокировку.

Дополнительные правила: по одному `домен/путь` на строку, например `instagram.com/reel`. Один домен блокирует весь сайт. Совпадают поддомены и границы сегментов пути; слова в заголовке, параметрах поиска и тексте страницы не являются причиной блокировки.

## Подпись и обновления

Пакет: `dev.noshorts.chrome`. Сборка использует существующий ключ ClosePaw из секретов GitHub Actions; ключ и пароли не находятся в исходниках.

SHA-256 сертификата: `25606cf1c6edbfdf2ce38285a9d1e94b5b5580b198c5e40f9ec4087f7cc447f2`.

Для обновления сохранять пакет и ключ, повышать `versionCode`. В этом workflow код версии равен `100000 + github.run_number * 2`; старая тестовая версия имеет код на единицу меньше. Не сбрасывать счётчик при замене workflow. Локальный `versionCode=2` — только запасное значение для разработки, он не подходит для обновления выпущенного APK.

CI устанавливает предыдущий подписанный APK, сохраняет пользовательское правило, выполняет `adb install -r` новой версии и проверяет сохранение времени первой установки, правила и разрешения Accessibility. Дополнительно проверяется состояние после перезагрузки.

## Проверка

Подробный результат: [TEST_RESULTS.md](TEST_RESULTS.md).

Выпуск 0.3.0 (`versionCode=100032`) проверен на Android 15 / API 35 с Chrome 154.0.8037.126: все шесть браузерных тестов прошли без пропусков. Обновление поверх предыдущего подписанного APK и автоматическое подключение службы после перезагрузки также прошли.

CI: `.github/workflows/build-noshorts.yml` в репозитории `onemorewe/workbook-7`, изолированная ветка `noshorts/android-verification`. Основной проект ClosePaw и его workflow не изменены.

Используются Android SDK 35, Android Gradle Plugin 8.7.3, Gradle 8.9, Java 17. Браузерные тесты запускаются из отдельного тестового APK `browser-tests`: они управляют Chrome и проверяют установленный подписанный выпускной APK NoShorts. Тесты не внедряются в процесс службы и не меняют её разрешение. Стандартная shell-диагностика службы содержит только состояние подключения, число блокировок и видимость покрытия; адресов страниц в ней нет. При наличии CI cache используется проверенный Chrome 154, иначе Chrome из образа SDK. Для Chrome 154.0.8037.126 x86_64 можно передать HTTPS-ссылку на APK через вход chrome_apk_url при ручном запуске workflow. Перед установкой проверяются пакет, версия и совпадение сертификата Google с предустановленным Chrome. Временные ссылки для передачи файла не должны оставаться в текущих исходниках.

```bash
bash test-core.sh
gradle :core:verifyRules :app:lintRelease :app:assembleRelease :browser-tests:assembleDebug :browser-tests:assembleDebugAndroidTest
```

Для подписанной сборки задать `KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, `NOSHORTS_VERSION_CODE`. Без этих переменных нельзя получить выпускной APK с постоянной подписью. Ключи не коммитить. Gradle wrapper в этом проекте не включён; CI устанавливает Gradle отдельно.

## Границы проверки

Служба работает со стабильным Google Chrome, пакет `com.android.chrome`. Она читает адресную строку через Accessibility, закрывает обнаруженную запрещённую страницу и запрашивает Back. Покрытие остаётся при временно неизвестном адресе; после подтверждённого разрешённого адреса снимается. Покрытие убирается вне Chrome. Кнопка выхода открывает фиксированную главную YouTube.

Samsung S24 Ultra непосредственно не подключён к тестам. Другие браузеры, Custom Tabs, приложение YouTube, полноэкранный режим, split screen и инкогнито не проверены. Если Chrome перестанет отдавать актуальный полный URL, новую страницу Shorts можно пропустить. Отключение службы, удаление приложения или принудительная остановка процесса снимают защиту. Это приложение не является Device Owner и не запрещает изменение настроек телефона.

Нет аналитики, рекламы, истории посещений и отправки адресов на сервер. URL других приложений не читаются.
