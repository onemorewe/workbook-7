# NoShorts 0.4 — Chrome на Android

Собственное приложение для Google Chrome (`com.android.chrome`): блокирует ленты по текущему URL и закрывает превью Shorts непрозрачными масками. Не использует VPN, интернет-разрешение, HTTPS-сертификаты, аналитику или историю посещений.

## Что закрыто

| Сайт | Заблокированные разделы | Сохраняется доступ |
|---|---|---|
| YouTube | Главная `/`, `/feed` со всеми вложенными путями, `/shorts` | Поиск `/results`, обычные видео `/watch`, страницы каналов |
| Instagram | Главная `/`, `/feed`, `/explore`, `/reel`, `/reels` | Direct, вход, страницы профилей, отдельные `/p` посты |
| LinkedIn | Главная `/`, `/feed` со всеми вложенными путями | Сообщения, вакансии, поиск, профили, вход |

Главная определяется как точный путь `/`, включая параметры. Она не означает весь домен. Проверяются границы домена и сегментов пути. Дополнительные правила пользователя работают как раньше: одна строка `домен/путь`; один домен блокирует весь сайт.

На главной YouTube закрываются и рекомендации, и посты сообщества. В NoShorts есть поиск YouTube и прямые переходы к сообщениям Instagram/LinkedIn и вакансиям LinkedIn.

## Превью Shorts

Служба использует `AccessibilityNodeInfo.targetUrl` Chromium. В YouTube также распознаёт явную подпись действия `play Short` у элементов без ссылки. Слово Shorts в обычном заголовке не является причиной скрытия. Маски следуют границам карточек, не перехватывают прокрутку и убираются вне Chrome. Нажатие сквозь маску по-прежнему проверяется блокировкой URL.

Это маскирование после получения Accessibility-дерева, а не удаление DOM или остановка загрузки картинки. При загрузке и быстрой прокрутке содержимое может мелькнуть; отсутствие любого видимого кадра не гарантируется. Элементы без адреса ссылки и без поддерживаемой подписи действия могут остаться видимыми. Обновления сайта и браузера требуют повторной проверки.

## Установка и обновление

Установить новый APK поверх существующего, затем проверить службу «NoShorts — Chrome» в специальных возможностях Android. При запрете Android: Настройки → Приложения → NoShorts → ⋮ → Разрешить ограниченные настройки. На Samsung проверить ограничения батареи и спящие приложения.

Пакет `dev.noshorts.chrome` и ключ ClosePaw сохранены. SHA-256 сертификата: `25606cf1c6edbfdf2ce38285a9d1e94b5b5580b198c5e40f9ec4087f7cc447f2`. Ключи и пароли находятся только в секретах GitHub Actions. `versionCode = 100000 + github.run_number * 2`; не сбрасывать счётчик при замене workflow. Локальный код 2 предназначен только для разработки.

CI устанавливает ранее выпущенный 0.3.0 APK с проверенным SHA-256, обновляет его через `adb install -r`, проверяет сохранение времени установки, правил и разрешения службы, затем проверяет перезагрузку. Браузерные проверки выполняет отдельный тестовый APK, без внедрения в процесс службы и без повторной выдачи разрешений.

## Ограничения

Работает только в стабильном Chrome. Нативные приложения Instagram, LinkedIn и YouTube не обрабатываются. Custom Tabs, другие браузеры, split screen, инкогнито, полноэкранное видео и особенности батареи Samsung не проверены. Версию 0.3.0 пользователь подтвердил рабочей на Samsung S24 Ultra; это не независимый SDK-тест 0.4.0 на этом телефоне.

Служба читает нативную адресную строку; при её отсутствии пробует URL документа WebView, а не адрес произвольной ссылки на странице. При неизвестном адресе сохраняет последнюю блокировку. Маски и полное покрытие убираются вне Chrome. При отключении службы, удалении или принудительной остановке приложения защита пропадает. Приложение не является Device Owner.

Диагностика службы содержит только подключение, число блокировок, состояние покрытия и число масок. Адреса и тексты страниц в production не записываются. Дампы страниц в CI относятся только к тестовым страницам эмулятора.
